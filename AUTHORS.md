## How to Contribute

If you'd like to contribute to Django Social, please see our [Contributing Guidelines](CONTRIBUTING.md).

All contributors will be recognized here. We value and appreciate all forms of contribution:

- Code contributions
- Bug reports and testing
- Documentation improvements
- Design and UI/UX feedback
- Community support and discussions

For details on how to get started, see [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
