# Support

Thank you for using Django Social! We're here to help.

## Getting Help

### 📖 Documentation

- Read the [README](README.md) for project overview
- Check the [Contributing Guide](CONTRIBUTING.md) for development setup
- Review the [Changelog](CHANGELOG.md) for release notes

### 💬 Discussions

Have a question or want to share ideas?

- [GitHub Discussions](https://github.com/MaxAndreev27/django-social/discussions)

### 🐛 Report a Bug

Found a bug? Please report it:

- [Create a bug report](https://github.com/MaxAndreev27/django-social/issues/new?template=bug_report.md)
- Search [existing issues](https://github.com/MaxAndreev27/django-social/issues) first

### ✨ Request a Feature

Want to suggest a new feature?

- [Create a feature request](https://github.com/MaxAndreev27/django-social/issues/new?template=feature_request.md)
- Check [existing feature requests](https://github.com/MaxAndreev27/django-social/issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement)

### 🔒 Security Issues

**Please do NOT report security vulnerabilities in public issues.**

- Review our [Security Policy](SECURITY.md)
- Email security issues to: security@example.com

## Community Support

### Stack Overflow

Tag your questions with `django-social` and relevant tags like `django`, `python`.

### Social Media

Follow us for updates and announcements:

- Twitter: [@django_social](https://twitter.com)
- GitHub: [@MaxAndreev27](https://github.com/MaxAndreev27)

## Response Time

We aim to respond to issues within:

- **Critical bugs**: 24-48 hours
- **Other issues**: 2-5 business days
- **Feature requests**: 1-2 weeks

Response times may vary based on community volunteers' availability.
